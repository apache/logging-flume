2.x.x

This release…​

Added

  • Add a Bill of Materials (flume-bom) that manages the versions of all published Flume artifacts (FLUME-3456)

  • Add PrometheusHTTPMetricsServer, which exposes Flume metrics to Prometheus (358)

  • Add RoutableProxyChannelSelector, which routes events to a channel selected by an event header (460)

Changed

  • Migrate the logging API from SLF4J to the Log4j API (459)

  • Move HTTPSource from flume-ng-core to the new flume-http-source module, so core consumers no longer depend on the Jetty HTTP stack (444)

  • Move the monitoring services from flume-ng-core to dedicated modules under flume-ng-instrumentation (445)

  • Replace Joda-Time with java.time (431)

  • Require Java 17 to build and run Flume (438)

  • Remove Jetty, Mina and Netty from the dependencies of flume-ng-core. The syslog and Netcat UDP sources now live in the dedicated flume-syslog-source and flume-netcat-source modules. (446, 448)

Fixed

  • Stop leaking exception details in HTTPSource error responses (442)

  • Fix order-dependent resolution of configuration properties that reference other properties (437)

  • Fix RFC 5424 timestamp parsing edge cases in the syslog sources (441)

Removed

  • Move the Avro and Thrift sources and sinks to their own repositories (431)

  • Move the HTTP sink and the IRC sink to the logging-flume-http and logging-flume-irc repositories (430)

  • Move the JDBC channel to the logging-flume-jdbc repository (FLUME-3458)

  • Move the JMS source and the Scribe source to the logging-flume-jms and logging-flume-scribe repositories (432)

  • Move the Kafka source, channel and sink to the logging-flume-kafka repository (FLUME-3457)

  • Move the legacy Avro and Thrift sources to their own repository (FLUME-3465)

  • Move the Morphline Solr sink to the logging-flume-morphline-solr repository (FLUME-3466, 426)

  • Move the Spring Boot support to the logging-flume-spring-boot repository (FLUME-3453)

  • Move the Twitter source to its own repository (FLUME-3455)

  • Remove the components depending on the Hadoop ecosystem: the HDFS, Hive, HBase and Kudu sinks

  • Remove the Log4j 1.x appender (434)
