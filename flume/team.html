Team

A successful project requires many people to play many different roles. Some write code or documentation, while others test releases, report problems, or contribute patches and ideas. All contributions are greatly appreciated, and you can get involved today.

Apache Flume has been maintained by the Apache Logging Services project since March 2024, when the Apache Flume Project Management Committee (PMC) was dissolved and Logging Services adopted the project. The current maintainers are listed on the Apache Logging Services team page.

Contributors

A hand-curated list of contributors is never complete, and someone always ends up omitted unintentionally. For this reason we do not maintain an official list of contributors: the Git history is the authoritative record, and only the exceptions are listed below.

To see the full list of contributors, run the following command on a clone of the source repository:

git shortlog --summary --numbered

or browse the list computed by GitHub.

As usual, praise should go to these people, while blame should go to the current maintainers.

The individuals mentioned below are the exceptions: those who climbed higher on the ASF contributor ladder and those whose contributions are not recorded in the Git history.

Contributors of the pre-Apache and Incubator era
